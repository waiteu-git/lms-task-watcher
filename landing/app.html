CLASS連携

時間割も、出席も、課題とひとつに。

CLASSの時間割を自動で取り込み、授業のコマから対応するLETUSコースへワンタップ。科目コードで課題と時間割を自動でひも付け。さらに授業の開始前に出席リマインドで、出席の取り忘れも防ぎます。

CLASS連携（時間割・科目連携・シラバス・更新通知）は、アプリに先立ってPC拡張機能「LETUS Task Watcher」v1.2.0で先行実装予定です。スマホ版の公開を待たず、PCで先に使えます。

できること

公開時に使える機能と、公開後のアップデートで順次追加していく予定の機能。

公開時に使える

LETUS課題の自動収集

履修コースの課題を自動で集め、締切順に一覧表示。

締切前プッシュ通知

24時間前・3時間前・1時間前にスマホへ直接通知。

朝まとめ通知

毎朝、その日以降の締切をまとめて1回お知らせ。

CLASS時間割の自動取込

履修時間割を自動で取り込んで表示。学期切替にも対応、コマから対応LETUSへ。

科目連携

科目コードでLETUS課題と時間割のコマを自動でひも付け。

コース更新のお知らせ

LETUSコースに教材や課題が追加されたら、時間割にバッジで表示。更新を見逃さない。

出席リマインド

授業の開始前にお知らせ。CLASSの出席登録ページへワンタップで、取り忘れを防止。

提出状態の表示

未提出・提出済みが一目でわかる。

見張り番プッシュ

締切間近の未提出課題を24h→6h→1hで追いかけ通知。提出を検知したら自動で止まる。

順次追加予定（アップデートで）

手動で課題を追加

自動収集に載らない課題も自分で追加。優先度・メモも。

カスタム通知ルール

通知のタイミングを自分好みに設定。

スヌーズ

通知を後で再通知。

統計・振り返り

提出状況をあとから振り返り。

ホーム画面ウィジェット

直近の締切をホーム画面に表示。

PC拡張機能とデータ同期

Chrome / Edge 拡張機能とアプリのデータを同期。

「順次追加予定」の機能は開発予定であり、内容・時期は変更される場合があります。

事前登録すると？

公開したときに、登録メール宛でお知らせします。届くのはそれだけ。宣伝メールを何通も送ることはありません。

PCなら、もう使えます

リタスの前身、PC向けの「LETUS Task Watcher（Chrome / Edge 拡張機能）」が公開中。ブラウザで課題の締切通知を今すぐ使えます。スマホ版の公開までは拡張機能でどうぞ。
