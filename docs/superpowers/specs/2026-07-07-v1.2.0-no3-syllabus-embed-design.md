# v1.2.0 No.3 シラバス埋め込み表示 — 設計

作成: 2026-07-07
種別: 機能設計（brainstorming成果）

## この文書の位置づけ

`docs/superpowers/specs/2026-07-06-v1.2.0-scope-change-design.md` の No.3「シラバス埋め込み表示」の詳細設計。No.2（CLASS時間割連携）で追加済みの `host_permissions`（`class.admin.tus.ac.jp`）と `src/core/syllabus.ts`（URL生成 `buildSyllabusUrl`・`academicYear`）を前提にする。

## 決定（確定した選択）

- **表示方法**: CLASSの静的シラバスHTMLを fetch し、**パースして整形表示**（サニタイズ丸ごと埋込やiframeではない）。
- **表示コンテナ**: **ダッシュボードのモーダル**（ドロワー相当）。シラバスは長文のため。
- **導線**: 時間割グリッドのコマ ＋ 課題カードのシラバスチップ（両方 `courseCode` 保持済み）。
- **キャッシュ**: `chrome.storage.local` に無期限キャッシュ（年内はほぼ不変）＋モーダルに手動リフレッシュ。
- **項目の取捨選択はしない**: 全セクションを整形表示（YAGNI: 固定スキーマに落とさず汎用のラベル→値で扱う）。
- **ポップアップ**: モーダルを持たず、チップは従来どおり新規タブでCLASSを開くフォールバック（クロスコンテキストの複雑化を避ける）。

## 実データの構造（取得済み4科目で確認）

`https://class.admin.tus.ac.jp/slResult/{年度}/japanese/syllabusHtml/SyllabusHtml.{年度}.{7桁}.html`（**ログイン不要・直リンク可**、UTF-8）。フィクスチャ: `src/core/syllabusFixtures/{9973344,9960192,9973365,9973139}.html`。

- ルート: `.syllabusArea` > `.syllabusInfo`。冒頭に `h2`（"シラバス情報"）と `.syllabus-info`（科目名・コード等のサマリ）。
- 本文は `.rowStyle`（行）の並び。各行に **`.colHeader`（ラベル、日本語＋英語併記）** と **`.colStyle`（非header＝値）** が1〜2個。
- ラベル体系・順序は4科目で完全一致（テンプレ生成）。ただし**固定ラベル決め打ちにせず**、行を汎用走査して追加/削除フィールドに堅牢にする。
- 代表ラベル: 科目授業名称（和文/英文）、授業コード、教員名/Instructor、開講年度学期、曜日時限、開講学科・専攻、単位数、概要、目的、到達目標、履修上の注意、準備学習・復習、成績評価方法、学修成果の評価、教科書、参考書・その他資料、授業計画、備考 ほか。

## アーキテクチャ（3ユニット）

### 1. `src/core/syllabusParse.ts`（純関数・テスト対象）

```ts
export type SyllabusSection = { label: string; value: string }
export type SyllabusDoc = {
  code: string
  titleJa: string
  titleEn: string
  sections: SyllabusSection[]
}
export function parseSyllabus(html: string): SyllabusDoc
```

- `.rowStyle` を走査。各行の `.colHeader` テキストからラベル、`.colHeader` でない `.colStyle` のテキストを値とする（複数値は改行結合）。空ラベルかつ空値の行はスキップ。
- ラベルは日本語部分のみを見出しに使う（先頭から最初のASCII英字ラン直前まで＝日本語ラベル。英語併記は落とす）。元ラベル全文は必要なら保持しない（YAGNI）。
- `titleJa`/`titleEn`/`code` は該当ラベル行（科目授業名称 和文・英文・授業コード）から取り出す。
- 依存: `node-html-parser`（既存依存、アプリ側で実行）。

### 2. `src/core/syllabusStore.ts`（fetch＋キャッシュ）

```ts
export type SyllabusCache = { doc: SyllabusDoc; fetchedAt: string }
export function getCachedSyllabus(year: number, code: string): Promise<SyllabusCache | null>
export function fetchAndCacheSyllabus(year: number, code: string): Promise<SyllabusCache>
```

- キー: `syllabus:{year}:{code}`。
- `fetchAndCacheSyllabus`: `fetch(buildSyllabusUrlByYear(code, year))` → `res.text()` → `parseSyllabus` → キャッシュ保存して返す。失敗は例外を投げ、呼び出し側（モーダル）がerror状態に落とす。
- 年度の齟齬回避: 既存 `buildSyllabusUrl(code, now)`（`academicYear(now)` で年度導出）に加え、`syllabus.ts` に **`buildSyllabusUrlByYear(code: string, year: number): string`** を追加し、`buildSyllabusUrl` はそれを `academicYear(now)` で呼ぶ薄いラッパにする。store/モーダルは `academicYear(new Date())` で得た `year` を明示的に渡す（キャッシュキーとURLの年度を一致させる）。
- `host_permissions` に `class.admin.tus.ac.jp` があるためダッシュボードのページコンテキストから直接 fetch 可（CORSはhost権限で解放）。

### 3. `src/components/SyllabusModal.tsx`（ダッシュボードのモーダル）

- props: `{ year, code, courseName, onClose }`。
- マウント時に `getCachedSyllabus` → 無ければ `fetchAndCacheSyllabus`。状態: `loading` / `error` / `loaded`。
- `error`: メッセージ＋「再試行」＋「CLASSで開く」（`buildSyllabusUrl` の外部リンク）。パース結果が空（sections 0）も同様に外部リンク誘導。
- `loaded`: ヘッダ（`titleJa` / `titleEn` / code / courseName）＋各セクションを「見出し（label）＋本文（value、改行保持 `white-space: pre-wrap`）」で縦に並べる。右上に手動リフレッシュ（`fetchAndCacheSyllabus` 再実行）と閉じる。
- オーバーレイ（背景クリック/Escで閉じる）。ダッシュボード幅のモーダル。

## データフロー / 導線

- ダッシュボードの `App` がモーダル状態 `syllabusTarget: { year, code, name } | null` を保持し、`openSyllabus(year, code, name)` を **`SyllabusContext`（React Context）** で供給。`syllabusTarget` があるとき `<SyllabusModal>` を描画。
- **時間割コマ**（`TimetableSection`）クリック・**課題チップ**（`AssignmentCard`）クリックで `openSyllabus` を呼ぶ。
- ポップアップは `SyllabusContext` を供給しない（`openSyllabus` 未提供）。その場合チップ/コマは従来どおり `buildSyllabusUrl` を新規タブで開く（`chrome.tabs.create`）。→ AssignmentCard/TimetableSection は「contextに `openSyllabus` があればモーダル、無ければ新規タブ」で分岐。

## エラー処理

- fetch失敗（ネットワーク/非200）: error状態＋再試行＋外部リンク。
- パース失敗（行0/構造変化）: 空docとして扱い外部リンク誘導（例外にしない）。
- キャッシュ読み書き失敗: fetchにフォールバック。

## テスト

- `syllabusParse.test.ts`: 4フィクスチャで `code`・`titleJa`/`titleEn`・主要セクション（概要/成績評価方法/授業計画 等）の存在と値先頭・セクション数の妥当性を検証。フィクスチャHTMLは `fs.readFileSync`（vitestのnode環境）で読む。
- `syllabusStore.test.ts`: `chrome.storage.local` スタブ＋`fetch` スタブでキャッシュヒット/ミス・再取得を検証。
- `SyllabusModal` は手動確認（実fetch）。

## 権限・リリース・逆流

- **manifest変更なし**（`class.admin` host_permission は No.2 で追加済み）。バックエンド変更なし。
- シラバスパーサは**拡張発**（litusはURL生成のみでパーサ無し）。逆流タスクで litus 側へ移植候補として記録。

## 非目標

- 英語ラベル/英語本文の別言語切替UI（初版は原文のまま縦並び）。
- 授業計画の表構造化（回→内容のテーブル化）。初版は本文テキストとして表示。
- 教科書リンク・MyKiTS等のリッチ化。
- シラバスのクロスデバイス同期（ローカルキャッシュのみ）。
- ポップアップ内でのモーダル表示。
