- 送付先の候補: 東京理科大学 総合情報システム部（LETUS/CLASS運用部門）。窓口URLと宛名は送付時に最新を確認する
- 送るもの: 下記メール本文（状況に合わせて[ ]を埋める）
- 添付・リンク: 利用規約・プライバシーポリシー・ソース公開先（LTW）・透明性ページ
- 大原則: 隠さない・盛らない・抵抗しない（要請があれば24時間以内に停止。範囲が不明瞭なら広めに停止）

## メール本文テンプレート

件名: 学生が個人開発した LETUS/CLASS 補助ツールについてのご報告

東京理科大学 総合情報システム部 ご担当者様

突然のご連絡失礼いたします。本学[学部・学科・学年]の[氏名]（学籍番号: [番号]）と申します。

私は在学生として、自分を含む学生が LETUS・CLASS 上の自分の情報（課題の締切、履修時間割、掲示など）を見やすくするための補助ツールを個人開発し、無償で公開しています。利用者が[増えてきた／◯◯名程度になった]ため、大学のシステムをお預かりする貴部門へ、先んじて自主的にご報告するものです。

**公開しているもの**
1. LETUS Task Watcher（PC向けブラウザ拡張機能・Chrome Web Store / Edge Add-ons で公開）
2. リタス（Litus）（スマートフォンアプリ・[開発中／公開状況]）

**設計上の配慮（両ツール共通）**
- 学生本人が自分のアカウントでログインした本人のデータのみを扱います。他人のデータや成績等の機微情報にはアクセスしません
- 取得した情報はすべて本人の端末内にのみ保存され、外部サーバーへ送信されません
- 大学サーバーへのアクセスは、学生本人が通常のブラウザ利用で行う操作の範囲・頻度に収まるよう抑制（間隔制御）を実装しています
- パスワード等の認証情報は保存・送信しません（ログインは大学の正規ログイン画面で本人が行います）
- 不具合や問題の判明時に、配布済みのツールを遠隔で停止できる仕組みを備えています
- 利用規約・プライバシーポリシーを公開し、利用者の同意を得てから動作します
  - 規約: https://lms.waiteu.dev/terms ／ プライバシー: https://lms.waiteu.dev/privacy

**お願い**
本ツールについて、大学のシステム運用上の支障やご懸念、学内規程との関係でご指摘がありましたら、ご連絡いただければ24時間以内に該当機能または全体の提供を停止いたします。事前にご確認いただきたい点や、運用にあたって守るべき条件がございましたら、ご指示ください。

ご確認のほど、よろしくお願いいたします。
