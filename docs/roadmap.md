## フェーズ2 — CLASS連携・シラバス・更新通知（＝v1.2.0本体 / アプリ実装に先立ち実装）

**2026-07-06 スコープ確定**（`docs/superpowers/specs/2026-07-06-v1.2.0-scope-change-design.md`）: フェーズ1.5の無料開放と合わせて **v1.2.0として一括リリース**する。`host_permissions` 追加で再審査になるため、無料開放と同じ機会にまとめる。

### 目的

モバイルアプリ「リタス」（フェーズ3）の時間割・科目機能の土台を先行して確立する。CLASSのパーサ・科目連携・シラバス・更新検知を拡張で実DOM検証し、安定版を litus へ逆流させる。

### v1.2.0 に含める内容

- **CLASS時間割**: 収集（Content Script）＋ダッシュボードのグリッド表示。ページ `Kmd008` の実地調査結果は `docs/superpowers/specs/2026-07-04-v2.0.0-mobile-app-initial-design.md` 付録A。収集範囲は**履修科目・時間割のみ**に厳格限定（成績等の機微情報は恒久的に除外）
- **科目連携**: 授業（時間割）とLETUSコースの自動ひも付け（CLASS 7桁コード ↔ LETUSコース名埋込コード）
- **シラバス埋め込み表示**: CLASSの静的HTMLシラバスを fetch し拡張内（科目ハブ）に整形表示
- **コース内容の更新通知**: 定義A＝`/mod/*/view.php` リンクの増減のみを差分検知してバッジ・通知
- `manifest.json` に `class.admin.tus.ac.jp` の `host_permissions` 追加 → Chrome Web Store 再申請（Phase C）
- 保存はローカルのみ・**バックエンド変更なし**。`/api/timetable`・クロスデバイス同期はリタス公開後の課題
- **4機能はすべて無料開放**。サブスク有料化の検討はリタス初版公開（2026年9月）まで凍結し、この期間は無料でのユーザー獲得に振る

### コード流通

純粋ロジック（パーサ・差分・シラバスURL生成）は**拡張で磨いて litus へ逆流**（共有パッケージ化はしない）。対応表・手順は上記スコープ変更設計を参照。
