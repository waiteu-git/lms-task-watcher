## フェーズ2 — CLASS連携（アプリ実装に先立ち実装）

### 目的

モバイルアプリ「リタス」（フェーズ3）の時間割機能の土台を先行して確立する。CLASSのパーサ・データモデル・バックエンドAPIをアプリ実装前に検証しておく。

### 内容

- CLASS（class.admin.tus.ac.jp）のセッション/SSO挙動・時間割ページ（`Kmd008`）のHTML構造調査（実地調査結果: `docs/superpowers/specs/2026-07-04-v2.0.0-mobile-app-initial-design.md` 付録A）
- 収集範囲は**履修科目・時間割のみ**に厳格限定（成績等の機微情報は恒久的に除外）
- 授業（時間割）とLETUSコースの対応付け（科目連携: 課題↔時間割の自動ひも付け）
- バックエンドに `POST/GET /api/timetable` を追加
- 時間割グリッドUI（Chrome拡張・リタス両対応のデータ設計）
- Chrome拡張で提供する場合は manifest.json に CLASSドメインの `host_permissions` 追加が必要 → Chrome Web Store 再申請
