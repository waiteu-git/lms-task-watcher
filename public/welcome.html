LETUS Task Watcher へようこそ

LETUSの課題期限を自動で集めて、締切前に通知します。まずは2分でセットアップしましょう。

セットアップは約2分

ご利用には利用規約への同意が必要です。同意いただくまで、課題の収集と通知は行いません。以下の手順に沿って進めれば同意できます。全文は利用規約でご覧いただけます。

1

ツールバーに固定しよう

固定しておくと、ワンクリックで課題一覧を開けます。

letus.ed.tus.ac.jp 🧩 ⋮
  1. アドレスバー右の 🧩 パズルピースのアイコンをクリックします。
  2. 一覧から 「LETUS Task Watcher」を探します。
  3. 右側の 📌 ピンのアイコンをクリックして固定します。
  1. アドレスバー右の 🧩 拡張機能のアイコンをクリックします。
  2. 一覧から 「LETUS Task Watcher」を探します。
  3. 右側の 👁 目のアイコンをクリックして「ツールバーに表示」にします。

固定すると、ワンクリックで今日の時間割と課題の締切がひと目で確認できます。

2

利用規約に同意しよう

固定したアイコンから、あと少しで使い始められます。

ツールバーに固定した拡張機能のアイコンをクリックすると、利用規約が表示されます。内容をご確認のうえ「同意して始める」を押すと、利用を開始できます。 同意いただくまで、課題の収集と通知は行いません。 未同意のあいだは、アイコンに 「!」 のバッジが表示されます。 全文は利用規約でご覧いただけます。

3

使い始めのステップ

最初に一度だけ、この3つを開けば準備完了です。

  1. CLASSで時間割を取り込む — CLASSにログインし「履修 → 学生時間割表」を開くと、今学期の時間割を自動で取り込みます。
  2. LETUS を開く — コースページを開くと、コースを自動登録し、時間割にある科目を自動で追跡対象にします。
  3. 「今すぐ更新」を押す — ポップアップの「今すぐ更新」で課題を取得。以降は自動でチェックします。
CLASS を開く → LETUS を開く → ダッシュボードを開く
4

あとは通知を待つだけ

1日1回、自動で課題をチェックします。期限が近づくとデスクトップ通知でお知らせするので、締切をうっかり見逃す心配がありません。通知のタイミングはダッシュボードから変更できます。
