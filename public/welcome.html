LETUS Task Watcher へようこそ

LETUSの課題期限を自動で集めて、締切前に通知します。まずは2分でセットアップしましょう。

① ツールバーに固定しよう

固定しておくと、ワンクリックで課題一覧を開けます。

letus.ed.tus.ac.jp 🧩 ⋯
  1. アドレスバー右の 🧩 パズルピースアイコンをクリック
  2. 一覧から「LETUS Task Watcher」を探す
  3. 右側の 📌 ピンアイコンをクリックして固定
  1. アドレスバー右の 🧩 拡張機能アイコンをクリック
  2. 一覧から「LETUS Task Watcher」を探す
  3. 右側の 👁 目のアイコンをクリックして「ツールバーに表示」

固定すると、ワンクリックで「今日の時間割」と課題の締切がひと目で確認できます。

② 使い始めのステップ

  1. CLASSで時間割を取り込む — CLASSにログインし「履修 → 学生時間割表」を開くと、今学期の時間割を自動で取り込みます
  2. LETUS を開く — コースページを開くと、コースを自動登録し、時間割にある科目を自動で追跡対象にします
  3. 今すぐ更新 — ポップアップの「今すぐ更新」で課題を取得。以降は自動でチェックします
CLASS を開く → LETUS を開く → ダッシュボードを開く

③ あとは通知を待つだけ

1日1回自動で課題をチェックし、期限が近づくとデスクトップ通知でお知らせします。通知のタイミングはダッシュボードから変更できます。
